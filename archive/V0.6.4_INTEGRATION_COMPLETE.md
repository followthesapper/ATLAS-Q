## Known Limitations & Future Work

### Current Limitations
1. **Rust backends are optional** - Require manual build
2. **No pre-built binary wheels** - Users must compile Rust code
3. **Limited to Linux/macOS** - Windows support not yet tested
4. **No GPU statevector** - CPU-only for now (v0.7.0 target)
5. **No Rust MPS** - Python MPS still slower than Aer (v0.8.0 target)

### Planned Improvements (v0.7.0+)
See [docs/FUTURE_WORK.md](FUTURE_WORK.md) for detailed roadmap:

**Phase 1 (1-2 months):**
- GPU statevector backend (1000× target speedup)
- Rust MPS backend (match/beat Qiskit Aer)
- Noise models for NISQ research

**Phase 2 (2-3 months):**
- Distributed simulation (multi-GPU)
- Advanced VQE features
- Production testing & CI/CD

**Phase 3 (4-6 months):**
- Research paper publication
- Hardware integration (IBM, IonQ, Rigetti)
- Custom FPGA/ASIC exploration
